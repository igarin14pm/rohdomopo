# ロードモポ

この Web アプリは無意味な徒労から人類を解放するカウントダウンを提供します。

## …これは何？

作業5分、休憩25分の "逆" ポモドーロタイマーです。

"ZEN Study プログラミングコンテスト 2026 夏" に応募する作品として制作されました。

## GitHub Pages

https://igarin14pm.github.io/rohdomopo/

## 機能

- "逆" ポモドーロタイマー機能

    1. "カウントダウンを開始" ボタンを押すと "五分間の徒労" (5分間作業) タイマーを開始
    2. 5分が経過すると、自動的に "二十五分間の解放" (25分間休憩) タイマーを開始
    3. さらに25分が経過すると、自動的に "五分間の徒労" タイマーを開始、以降繰り返し

    - 音声でタイマーの切り替わりをお知らせ
    - 音声とテーマ色の変化で歓喜と絶望を演出

- ブラウザ上でテストを実行 (https://igarin14pm.github.io/rohdomopo/test/)

## ローカルでの実行方法

リポジトリをクローンし、Node.js の `npx serve` 等でローカルサーバを立てて実行してください。

ES Modules を使用しているため、 index.html をファイルとして開く方法では正常に動作しません。
